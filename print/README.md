# Print Pack

KCC Code Club: Game Makers. Ready-to-print PDFs, all A4 unless noted.

Everything here is **generated** from the markdown in `handouts/`, `admin/` and
`curriculum/` by `build/build_print.py`. Edit the markdown and rebuild — don't edit a PDF.
See `build/README.md`.

## Filling in the details

Most of these have dates, a venue, a contact or the agreed insurance wording to fill in before
they go out. Editable Word copies of everything except the handouts are in **`editable/`**, with
every placeholder highlighted. Fill one in, then Save As somewhere outside the repo — the
templates get overwritten when the pack is rebuilt. See `editable/README.md`.

## Printing them

The handouts are designed to survive a **black-and-white photocopier**, which is what
community venues have. Every Scratch block carries its category name and the fills are
spread across the greyscale range, so Motion still reads differently from Control with no
colour at all. Sixteen students over eight weeks is 128 pages a term; mono is the sane
default.

The **certificate is the exception** — print that one in colour if you can. It is the
thing that goes on a fridge.

## Certificates

`certificate-template.html` is the editable source. Open it in a browser, duplicate the
whole `<div class="cert">` block once per student, type each child's name into `.name` and
a specific award into the `.line` under "Special mention for", then print to PDF.

Make the mentions specific — "Most Determined Debugger", "Best Boss Battle", "Most
Original Idea". A specific line is worth ten generic ones and it takes five minutes to
write twelve of them. Everyone gets one; this is not a competition.

Note that `certificate-template.html` is regenerated by the build, so put your filled-in
copies somewhere else before you rebuild.
