### Today's big idea

A program is a list of instructions, done **in order**, exactly as you wrote them.

Computers don't guess what you meant. That's not because they're stupid — it's because
they're *very* obedient.

---

### Words to know

| Word               | What it means                                          |
| ------------------ | ------------------------------------------------------ |
| **sprite**   | A character or object in your game                     |
| **stage**    | The area where your game happens                       |
| **backdrop** | The picture behind everything                          |
| **block**    | One instruction                                        |
| **script**   | A stack of blocks joined together                      |
| **bug**      | Something in your code that doesn't do what you wanted |

---

### Class activity — Name Dance

Make a sprite that says your name and then dances.

1. Pick a sprite you like.
2. Add `when green flag clicked`.
3. Add `say [your name] for 2 seconds`.
4. Make it dance: `move 50 steps`, `wait 0.5 seconds`, `move -50 steps`, `wait 0.5 seconds`, `turn 15 degrees`.
5. Try adding `next costume` in between the moves.
6. Try `change size by 10`. Run it twice. What happens?

**Stuck?** Check that your blocks are actually joined to the `when green flag clicked` block.
If there's a gap, nothing runs.

### If something breaks

1. Say out loud: *what did I expect, and what did it actually do?*
2. Change **one** thing and try again.
3. Check you're looking at the right sprite.
4. Ask a friend before you ask a grown-up.
