# External Resources

Everything here is free. The point of this file is that you should not be writing curriculum
from scratch when hundreds of hours of tested material already exist — use these for extension
work, for catch-up, for fast finishers, and as the backbone if you ever need a substitute
volunteer to run a session cold.

## The core platform

- **[Scratch](https://scratch.mit.edu)** — the editor, in a browser
- **[Scratch Desktop](https://scratch.mit.edu/download)** — the offline editor. Carry the
  installers on a USB stick and offer to install it in week one; the laptops are the families' own
- **[Scratch for Educators](https://scratch.mit.edu/educators)** — teacher accounts, class
  management, and their own teaching guides
- **[Scratch Teacher Accounts Guide (PDF)](https://resources.scratch.mit.edu/www/guides/en/scratch-teacher-accounts-guide.pdf)**

## Project libraries — the ones to actually use

### Raspberry Pi Foundation project pathways

The best free structured Scratch material there is. Each project is a self-contained step-by-step
guide a child can follow independently, which makes them perfect for fast finishers and absent
students.

- **[Introduction to Scratch](https://projects.raspberrypi.org/en/pathways/scratch-intro)** —
  sprites, scripts and loops. Roughly weeks 1–3 of this course. Projects: Space talk, Catch the
  bus, Find the bug, Silly eyes, Surprise! animation, I made you a book
- **[More Scratch](https://projects.raspberrypi.org/en/pathways/more-scratch)** — broadcast,
  decisions and variables. Roughly weeks 4–6. Projects: Broadcasting spells, Grow a dragonfly,
  Drum star, Next customer please, Don't fall in!, This sprite needs you
- **[Further Scratch](https://projects.raspberrypi.org/en/pathways/further-scratch)** — clones,
  My Blocks and boolean logic. Beyond this course. Where to send anyone racing ahead

**"Don't fall in!"** in the More Scratch path is the closest thing to Sky Catcher and is a
natural follow-on project for the holidays.

### Code Club Aotearoa

- **[Code Club Aotearoa](https://codeclub.nz)** — the New Zealand Code Club network. Free
  projects, volunteer-run clubs, local support
- **[All Code Club projects](https://codeclub.nz/page/all-code-club-projects)** — the full library
- **[Starting a Code Club](https://codeclub.nz/page/start-a-code-club-at-your-school)** — worth
  reading even if you stay independent, and worth considering joining
- They also host **Digital Pīkau** projects with an Aotearoa context (Kōhiti Watch, My Kupu App,
  Move the Hoiho) and the **Moonhack** projects (Matariki, Satellites in Space) — good one-off
  sessions if you ever need to fill a week

### Others worth knowing

- **[Harvard Creative Computing Curriculum](https://creativecomputing.gse.harvard.edu)** — the
  original Scratch curriculum guide. More theory than you need for eight weeks, but excellent
  on *why* the pedagogy works the way it does
- **[Google CS First](https://csfirst.withgoogle.com)** — themed Scratch project packs with
  videos. Good if you want a session that runs itself
- **[ScratchEd](https://scratched.gse.harvard.edu)** — a community of Scratch educators. Useful
  when you hit a teaching problem someone has definitely already solved

## For volunteers who want to understand the teaching better

- The **Raspberry Pi Foundation's mentor notes** attached to each pathway — click "Mentor
  information" on any pathway page. Short, practical, written for exactly your situation
- **Semantic waves** and **PRIMM** are the two teaching frameworks worth twenty minutes of
  reading if you're enjoying this and want to get better at it. Both are about moving between
  concrete and abstract, which is precisely what the unplugged warm-ups in this course are doing

## Where students go next

Put these on the week-eight keep-going sheet:

1. **[More Scratch](https://projects.raspberrypi.org/en/pathways/more-scratch)** if they haven't
   done it — the direct next step
2. **[Further Scratch](https://projects.raspberrypi.org/en/pathways/further-scratch)** for the
   ones who found this easy
3. **The club studio** — seeing and remixing each other's work is more motivating than any
   official project
4. **The Python track**, next term, for anyone 12 or over who's ready for text
